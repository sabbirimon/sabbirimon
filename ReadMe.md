## IMON · Let’s Code Together

### Hey, I'm Sabbir Hassan Imon 👋

An open-source builder from **Dhaka, Bangladesh**, exploring the space between **local-first AI, Android, systems, and cloud infrastructure**. I like useful tools, curious experiments, and giving serious software a little personality.

My roots are in DevOps and networking: Linux, containers, Kubernetes, and the radio networks that connect us. These days, my public projects also explore device tooling, recovery, and experimental model execution.

### A few things I'm building

| Project | What it explores | Built with |
| :--- | :--- | :--- |
| [**Meshlit**](https://github.com/sabbirimon/meshlit) | Local-first AI chat, coding workspaces, and bots for Android and desktop. | Kotlin |
| [**OmniCast**](https://github.com/sabbirimon/OmniCast) | Mirror, control, and record Android over USB or Wi-Fi, with desktop device tools. | Kotlin |
| [**OmniRecovery**](https://github.com/sabbirimon/OmniRecovery) | Cross-platform data recovery, verified USB acquisition, and forensic inspection. | Rust |
| [**HyperL**](https://github.com/sabbirimon/HyperL) | Experimental model execution, sharding, and heterogeneous compute. | Kotlin |
