# Original pixel landscapes

Generated on 2026-11-17 for the IMON portfolio using the built-in `image_gen` tool in generation mode. Each landscape used a separate call with `transparent_background: false`. No stock files, external image APIs, CLI image generator, or downloaded reference images were used.

All three outputs are 1672 × 941 pixels (approximately 16:9), web optimized from the original PNGs with Pillow's WebP encoder at quality 90, method 6. The images retain their original dimensions and composition, with perceptual compression to reduce download size. The generated PNG originals remain in the local generated-images directory. The web exports were visually reviewed for pixel detail and color. The images contain no text, branding, or interface elements; all artwork is original generated illustration.
