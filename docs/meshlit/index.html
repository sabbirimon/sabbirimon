Verify your download

To verify the Windows archive, run this command with GitHub CLI. On Linux or Apple Silicon, substitute the filename you downloaded.

gh attestation verify "Meshlit-Studio-Windows-X64.zip" --repo sabbirimon/meshlit --signer-workflow sabbirimon/meshlit/.github/workflows/full-studio.yml --source-digest 25ff596f9067b728b07471c929abc5f0d8518cf5

For the Intel Mac archive, use its dedicated build workflow.

gh attestation verify "Meshlit-Studio-macOS-X64.tar.gz" --repo sabbirimon/meshlit --signer-workflow sabbirimon/meshlit/.github/workflows/intel-release.yml --source-digest c8deafd6a79a91b37682812adaca1b7ff83b6f79
