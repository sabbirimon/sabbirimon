Meshlit

Local AI for Android and desktop with GGUF models, agent tools and a dedicated coding workspace in Meshlit Studio.

The Android app uses Kotlin and Jetpack Compose. Native Meshlit Studio uses a Rust launcher, a JavaScript coding workbench and llama.cpp inference. In Studio, you can chat with a local GGUF model, open a coding project, or pair approved devices to share models and stream replies. Pairing over the internet uses a configured HTTPS relay.
