Verify a desktop preview

Open a successful preview build and check the source commit. Sign in to GitHub to download the artifact for your system. Extract the outer Actions archive. With GitHub CLI, run this command on the enclosed installer or HyperL ZIP, using its actual filename.

gh attestation verify "Meshlit.msi" --repo sabbirimon/meshlit --signer-workflow sabbirimon/meshlit/.github/workflows/multiplatform-preview.yml --source-ref refs/heads/feature/desktop-inference-profiles

A successful result matches the file digest, repository, workflow and branch. Compare the reported commit with the one you selected. Earlier downloads may predate attestations. Windows publisher checks and macOS notarization use separate credentials.
