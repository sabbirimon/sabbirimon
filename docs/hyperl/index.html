HyperL

Native Rust engine for memory-budgeted tensor workloads, with Python graph tools and a desktop inference preview.

Run dense tensor projections from SafeTensors weights on a CPU or a supported wgpu adapter. Python graph tools lower typed operations to StableHLO for compilation with XLA or IREE. HyperL Studio includes a native CPU inference server and a starter Qwen2.5 model for offline chat.
