The rulebook

Editor access
Sign in with an authorized editor account. Permissions are checked by the server for each management request.
Drafts and revisions
Use Course studio for courses, labs and articles. Use Content for site notices. If another editor published first, copy your draft and reload the current revision.
Member records
A pending member activates by signing in with the matching email. Deleting an active account removes its login, cloud progress and leaderboard membership. Confirm the selected email before deletion.
Metrics and retention
Declared automation and unverified browser totals describe observed traffic. Export the needed logs before pruning. The date filter deletes entries strictly before the confirmed UTC date.
Snapshot scope
Snapshots cover authored library items, four editable notices, featured destination, title palette and the metrics setting. Accounts, scores, logs and built-in lessons are outside the snapshot.
Restore and reset
Restore accepts a site JSON snapshot up to 5 MB and requires RESTORE SITE CONTENT. Reset deletes authored content, clears notices, restores defaults and pauses metrics. It requires RESET SITE CONTENT. Both actions first download a copy of current editable content.
