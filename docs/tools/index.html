Verification only. These are plain, fast hashes — there is no key stretching here. Do not use them to store passwords; use a dedicated password hashing function such as Argon2 or bcrypt.

DNS lookup

    
Resolve A, AAAA, MX, NS and TXT records over DNS-over-HTTPS.

    
This is the one tool that leaves your browser. The lookup is sent to Cloudflare's DNS-over-HTTPS endpoint (cloudflare-dns.com) together with the domain name you type. Nothing else on this page is uploaded. If the request fails — blocked by CORS, offline, or filtered by an ad blocker — the tool says so and shows no records rather than inventing one.

Port checker

    
Validate a port number and look up the well-known service that usually lives on it.

    
This tool does not scan anything. It never opens a connection, never touches the network and never probes your machine — it only validates the number you type and matches it against a static list of registered service ports.

YAML formatter

    
Re-indent a YAML document with a hand-written indentation parser, or minify it onto one line. Malformed YAML is reported with its line number.

    
Subset parser. This tool reads the block-style YAML that appears in configuration files — nested maps, lists, flow collections, quoted scalars and block scalars. Anchors, aliases, tags, multi-document streams and complex keys are out of scope, and a document using them falls back to a conservative line-based re-indent (the panel says so when it happens).
